# Student Management System

Система управления данными студентов.

## Технологический стек

* **Java:** 21
* **Сборка:** Apache Maven
* **Тестирование:** JUnit 5
* **Анализ покрытия кода:** JaCoCo Maven Plugin

## Инструкция по сборке и запуску

### Запуск тестов
Для прогона всех модульных тестов выполните команду:
```bash
mvn test
